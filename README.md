# Marquis — Considered Bathroom Furniture

A minimalist Single Page Web Application showcasing Marquis Australian bathroom joinery collections, product specifications, and trade download resources.

## Features

- **Collection Catalogs**: Explore 5 distinct ranges (*Marquis*, *Beaumont*, *Tradelink*, *Samios*, *Blue Space*).
- **Product Detail Views**: High-resolution imagery, dimensions, and joinery specifications for every product.
- **Technical Downloads**: 1-click downloads for Spec Sheets, Order Forms, Info Sheets, and Photo Assets.
- **Dynamic Tag Filtering**: Staggered animated filtering by category (*Vanity*, *Compact*, *Mirror Cabinet*).
- **Minimalist Navigation**: Elegant view-switch transitions using Elma Sans typography.

## Tech Stack

- **HTML5 & CSS3** (Vanilla CSS Design System & Tailwind CSS)
- **Vanilla JavaScript** (Client-side Hash Router & State Manager)
- **Typography**: Elms Sans, Fraunces Serif, and IBM Plex Mono

## Quick Start

Simply open `index.html` in any modern browser. No build tools or server setup required.
